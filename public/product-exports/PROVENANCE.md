# Product export provenance

`azure-estate-report.html` is generated by compiling the current azdocs checkout
and running `tests/report_preview.rs::writes_every_theme_in_every_format` in a
new temporary directory. It uses the canonical `tests/common/mod.rs` fixture,
the application's HTML renderer and its current `field-report` theme. The resulting HTML
is included byte-for-byte, with no website styling injected into the report.

Run `pnpm refresh:exports` to regenerate it. This requires the azdocs checkout
(by default `../azdocs`, or `AZDOCS_SOURCE`), Rust and its cached dependencies.
Existing files under the application's `output/` directory are never used.

`manifest.json` records the source revision, generation time, a SHA-256 of the
renderer inputs and fixture, and the resulting HTML checksum. Local development
and builds reject an export whose inputs have changed. Cloud builds without a
local azdocs checkout verify the saved artifact checksum; they do not compile
Rust or claim that the export matches an unverified remote revision.
